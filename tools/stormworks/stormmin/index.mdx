StormMin は、Stormworks のビークル Lua が持つ 8192 文字制限にコードを収めるための、全体最適化 Lua コンパイラ (minifier) です。Web 版、CLI、Node/ブラウザ向けライブラリ (npm `@stormcat-works/stormmin`) として利用でき、大規模な Lua スクリプトを書くビークル開発者向けのツールです。

- Web 版での minify
- CLI/ネイティブバイナリでの minify
- Node/ブラウザ向けライブラリとしての組み込み
- 目標サイズに到達した時点で停止する探索
- require によるモジュール分割への対応
- 意味を壊していないか確認する semantic 検証器

<Card title="StormMin を開く" icon="arrow-up-right-from-square" href="https://www.makkii.jp/tools/stormworks/stormmin/">
  Web 版はブラウザで直接利用できます。CLI やライブラリは npm から入手できます。
</Card>
