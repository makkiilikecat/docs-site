<Note>
AI 機能は仕様変更中のため、ここでは概要のみを記載しています。
</Note>

Storm Code には、プロジェクトのコードを踏まえて対話できる AI パネルが組み込まれています。

- **Chat モード** — ファイルの内容や lint の結果を読み取ったり、コマンドを実行したり、承認を得たうえでファイルを読み書きしたりできる、対話形式のアシスタントです。
- **Agent モード** — Chat モードと同じ画面に加えて、AI が立てた作業計画を提示し、承認を得てからコードを書き、自己レビューして結果を報告する、より自律的なモードです。

このほか、エラー内容を AI に説明してもらう機能など、チャットパネルを開かずに使える簡易的な AI 機能もあります。
