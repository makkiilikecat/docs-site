Storm Code は、共有 URL を発行するだけでブラウザから他のユーザーを招待し、同時にコードを編集できる共同編集機能を持っています。アカウント登録は不要です。

<Note>
共同編集はブラウザ版のみの機能です。
</Note>

## セッションを開始する

サイドバーの「共同編集 (Collab)」パネルにある「セッションを開始 (Share)」ボタンからセッションを開始できます。開始すると共有用の URL が発行され、URL のコピー・自分の表示名の変更・現在の参加者一覧を表示するダイアログが開きます。「セッション終了」ボタンで、いつでもセッションを終了できます。

セッションが開始されると、それまで編集していたワークスペースがそのまま共有対象になります。新しく別のプロジェクトを用意する必要はありません。

## 参加する

共有された URL を開くと、自分のワークスペースを開かずに参加用の画面が表示され、自動的にホストのワークスペースへ接続します。接続が完了すると、ホストと同じファイルツリーが表示され、編集を始められます。「退出」ボタンでいつでもセッションから抜けられます。

## 共有 URL について

- 共有 URL を持っている人は、閲覧専用ではなく**全員が編集者**として参加できます。閲覧専用のリンクはありません。
- 発行済みの URL を無効化する方法は、セッションを終了する以外にありません (個別の参加者だけを追放したり、URL だけを再発行したりする機能はありません)。
- URL は推測困難なランダムな値を含んでいますが、これは礼儀としての仕組みであり、セキュリティ上の保証ではありません。画面に表示されているコードは誰でもコピーできます。

## 同時編集の挙動

ファイルの本文はリアルタイムの共同編集技術(CRDT)で同期されるため、複数人が同じファイルを同時に編集しても、両者の変更が自動的にマージされます。手動でコンフリクトを解消する必要はありません。

- 他の参加者のカーソル位置や選択範囲が、参加者ごとに割り当てられた色で表示されます。
- 表示名は既定でランダムな日本語の名前 (例: 「陽気なタヌキ」) が割り当てられますが、いつでも変更できます。
- Explorer には、各ファイルを誰が開いているかを示すアイコンが表示されます。参加者一覧の項目をクリックすると、その人が開いているファイルへジャンプできます。
- ファイル・フォルダの作成/リネーム/削除/移動は、ホストだけが直接行えます。ゲストがこれらの操作をすると、ホストへ転送されて処理されます。
- 実行 (Runtime) やデバッグの状態は共有されません。参加者それぞれが自分のブラウザ上でスクリプトを実行します。

## ホストが切断した場合

ホストが一時的に切断すると、ゲストは編集できなくなり「ホストの再接続を待っています…」と表示されます。60 秒以内にホストが再接続すれば、そのまま編集を再開できます。60 秒以内に再接続しなかった場合や、ホストが明示的にセッションを終了した場合は、セッションは終了します。

<Warning>
セッションが終了すると、ゲスト側が共有されていたデータ (ファイル・実行状態・開いていたタブなど) はすべて破棄されます。セッション終了前に保存する手段は用意されていません。編集内容を残したい場合は、セッション中に自分の手元にコピーしておいてください。ホスト側のワークスペースは、セッションが終了しても失われません。
</Warning>

## その他の制約

- 編集には常時オンラインである必要があります。オフラインで編集した内容を後でマージする仕組みはありません。
- ゲストとして参加している間は、Export Zip / Import Zip / Open Folder / Open File / Reset All は使えません。
- プロジェクトのサイズが一定を超えると、セッションは自動的に終了しソロ編集に戻ります。
- 画像ファイルは 1 ファイル 1MB までしか同期できません。これを超える画像は同期に失敗し、エラーが表示されます。
