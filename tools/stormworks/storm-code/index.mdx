Storm Code は、Stormworks 向けの Lua スクリプトをブラウザ内で書き、実行/デバッグし、minify して貼り付けるまでの一連の流れを 1 つの環境で完結させるツールです。マイクロコントローラーの Lua スクリプトを開発するビークル開発者向けのツールです。

- Lua 5.3 WASM による正確なエミュレーション
- require や sim.\* ライブラリへの対応
- 編集中の lint
- StormMin と統合された minify 機能
- URL 共有によるリアルタイムの共同編集
- GUI 描画エディタ (Design)
- AI チャット/エージェント

  ブラウザで直接利用できます。
</Card>
