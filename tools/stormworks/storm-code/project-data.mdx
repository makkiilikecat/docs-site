## 保存の仕組み

Storm Code に明示的な「保存」操作はありません。編集内容はブラウザの IndexedDB に自動的・継続的に反映されます。メニューの `Auto Save` は常に有効で無効にはできません。`Ctrl+S` を押しても何も起こりません (押さなくてもデータが失われることはありません)。

データはブラウザローカルに保存されるため、ブラウザのデータを消去したり、別のブラウザ・別の PC で開いたりすると、ワークスペースは引き継がれません。ブラウザをまたいで移行するには、後述の Export Zip / Import Zip を使います。

## File メニューの操作

`File` メニューから次の操作ができます。

| 操作 | 内容 |
|---|---|
| `New File` (`Ctrl+N`) | アクティブなファイルと同じフォルダに新規 `.lua` ファイルを作成します |
| `Open File...` | ローカルの `.lua` ファイルをワークスペースのルートに読み込みます |
| `Open Folder...` | ローカルフォルダの内容でワークスペース全体を置き換えます |
| `Export Zip...` | ワークスペース全体を `.zip` としてダウンロードします |
| `Import Zip...` | `.zip` の内容でワークスペース全体を置き換えます |
| `Reset All (Factory Reset)...` | ワークスペースを完全に初期化します |

`Open Folder...` / `Import Zip...` / `Reset All...` は、現在のワークスペースを完全に削除する破壊的な操作です。実行前に確認ダイアログが表示され、`Import Zip...` ではさらに「元に戻せません」という警告文と、AI チャット履歴・ファイル履歴も置き換わる旨が示されます。

## Export Zip / Import Zip でブラウザ間を移行する

`Export Zip...` は、ワークスペース全体 (ファイル・フォルダ・Design・AI チャット履歴) を 1 つの zip ファイルとしてダウンロードします。ファイル名は `storm-lua-runner-workspace-YYYYMMDD-HHMMSS.zip` の形式です。

別のブラウザや別の PC で `Import Zip...` からこの zip を読み込むと、エクスポート時のワークスペースがそのまま復元されます。

- **含まれるもの**: すべてのファイル・フォルダ・Design、AI チャットの会話履歴。
- **含まれないもの**: AI 設定と API キー。これらは個人の秘匿情報であり、共有される前提の zip に混ぜない設計になっているため、ブラウザごとに個別に設定し直す必要があります。UI のレイアウトなどブラウザ固有の状態も含まれません。

<Warning>
`Import Zip...` はワークスペース全体を置き換える操作です。取り込む zip に含まれるパスが 1 つでも不正な場合、インポート全体が中断され、何も取り込まれません。
</Warning>

エクスポートされた zip は、ローカルの VS Code などで直接開ける一般的な zip 構造になっています。Storm Code 以外で作った (専用の管理ファイルを含まない) zip でも、`Import Zip...` から読み込めます。

## ワークスペースのリセット

`Reset All (Factory Reset)...` は、ワークスペースとブラウザに保存されたセッション状態・AI チャット履歴・ファイル履歴をすべて削除します。実行するには確認ダイアログに続けて `RESET` という文字列の入力が必要です。AI 設定 (API キーを含む) は削除されません。

## 同時に開けるタブ数

同じワークスペースは 1 つのブラウザタブでしか編集できません。既に編集中のタブがある状態で別のタブを開くと、そちらは「他のタブでこのワークスペースを開いているため、読み取り専用モードで起動しました。編集するには他のタブを閉じてください。」と表示され、読み取り専用になります。

## 複数プロジェクトについて

Storm Code のワークスペースは、ブラウザごとに 1 つだけです。複数のプロジェクトを作成して切り替えるような機能はありません。別のプロジェクトを扱いたい場合は、`Export Zip...` で現在の内容を保存してから `Open Folder...` や `Import Zip...` で別の内容に切り替えてください。
