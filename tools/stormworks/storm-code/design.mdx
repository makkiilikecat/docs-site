<Note>
Design は仕様変更中の機能のため、ここでは概要のみを記載しています。
</Note>

Design は、マイクロコントローラーの画面 (モニター) 表示を、Lua コードを書かずに GUI 上で組み立てる機能です。Explorer から `.design` ファイルとして作成します。

再利用可能な描画レイアウト (View) を定義し、1 つまたは複数のモニターにレイアウトを配置して、描画要素や部品を視覚的に配置していきます。作成した Design は読み取り専用の Lua コードとして生成され、他の `.lua` ファイルから `require` して使ったり、単体で minify してゲームに貼り付けたりできます。
