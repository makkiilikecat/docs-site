---

Physics Frame Codegen は、Stormworks の Physics Sensor が計算する任意のオフセット点の物理量を、必要な出力だけに絞った Lua コードに変換するブラウザアプリです。マイクロコントローラーの Lua スクリプトに Physics Sensor の計算結果を組み込みたいビークル開発者向けのツールです。

- 複数の仮想センサー/オフセット設定を管理できる
- 静的オフセットと動的オフセットを選択できる
- position、velocity、acceleration などの出力項目を個別に選択できる
- 設定を localStorage に自動保存し、JSON でインポート/エクスポートできる
- 生成した Lua コードをダウンロードできる
- 生成コードのサイズを事前に見積もれる
