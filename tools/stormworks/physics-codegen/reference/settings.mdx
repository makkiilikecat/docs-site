左パネルの「Basic Settings」で、生成コード全体に関わる項目を設定します。

| 項目 | 既定値 | 内容 |
|---|---|---|
| 関数名 (Lua Function Name) | `physConvert` | 生成される Lua 関数の名前。`[A-Za-z0-9_]` 以外の文字は `_` に置き換えられ、先頭の数字などは取り除かれます |
| 動的角度単位 (Dynamic Unit) | `rad` | 動的オフセットの実行時引数（pitch/yaw/roll）の単位。`rad` を選ぶと度数法からラジアンへの変換コードが不要になり、生成コードが短くなります |
| 説明コメント含める | オン | 生成コードに `-- [[ オフセット名 ]]` などの説明コメントを挿入します |
| 1-3=0位置自動補完 | オン | 下記「位置自動補完」を参照 |
| ch15-17直利用 | オン | 下記「Composite Input ch15〜17」を参照 |
| 目標文字数（Lua 出力パネルの文字数表示の中にある入力欄） | 8192 | 生成コードの目標文字数。Stormworks のマイクロコントローラーの Lua スクリプトブロックの上限文字数に合わせた値です |

<Note>
  目標文字数はコード生成そのものを止めるハードリミットではなく、UI 上の「残り」表示の基準値です（`目標文字数 − local短縮推定`）。実際に貼り付ける前に、Stormworks 側の文字数制限を超えていないか確認してください。
</Note>

## Physics Frame Codegen が読み取る Composite Input チャンネル

生成コードは、Physics Sensor から Composite Input 経由で渡された次のチャンネルを読み取ります。この一覧は Stormworks の Physics Sensor 全体の仕様ではなく、Physics Frame Codegen が実際に読み取る範囲に限った対応表です。

| チャンネル | 内容 |
|---|---|
| ch1〜3 | Physics Sensor のワールド位置（右・上・前方向、メートル） |
| ch4〜6 | Physics Sensor 自体のワールド向き（オイラー角、常にラジアン） |
| ch7〜9 | Physics Sensor のローカル（センサー基準）線速度（m/s） |
| ch10〜12 | Physics Sensor のローカル（センサー基準）角速度 |
| ch13〜14 | 使用しません |
| ch15 | `ch15-17直利用` が有効な場合のみ、対象オフセットの Tilt Z の直接値として使用 |
| ch16 | `ch15-17直利用` が有効な場合のみ、対象オフセットの Tilt X の直接値として使用 |
| ch17 | `ch15-17直利用` が有効な場合のみ、対象オフセットの Compass の直接値として使用 |

<Warning>
  ch15〜17 は Physics Sensor が本来出力する内容ではなく、Physics Frame Codegen 独自の入力規約です。Tilt センサーなどの出力を Composite Input のこれらのスロットへ手動で配線した場合にのみ意味を持ちます。配線していない場合は「ch15-17直利用」をオフにしてください。
</Warning>

加速度（Local/World Accel、Angular Accel）はどのチャンネルからも取得しません。対応する速度・角速度の値を毎tick差分し、60倍する（`(今回の値-前回の値)*60`）ことで算出しています。マイクロコントローラーの `onTick` は60Hzで実行されるという前提です。

## 位置自動補完

`World Pos` を出力する設定にすると ch1〜3 を読み取ります。「1-3=0位置自動補完」が有効な場合、ch1〜3 がすべて厳密に0の tick では、Physics Sensor がまだ値を報告していないとみなし、直近のローカル速度（ch7〜9）をワールド座標系に変換して積分し、位置を補完します。0以外の値が来た時点で、その値をそのまま採用します。

## 動的角度単位と静的オフセットの角度単位

「動的角度単位」は、動的オフセットの実行時引数（毎tick渡す6要素配列の pitch/yaw/roll）にのみ適用されます。静的オフセットの Pitch/Yaw/Roll フィールドは、この設定に関わらず常に度数法です。また Physics Sensor 自体のオイラー角（ch4〜6）は常にラジアンで渡ってくる仕様のため、この設定の影響を受けません。
