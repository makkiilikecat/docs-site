Number Codec Compiler は、Stormworks のマイクロコントローラー向けに、数値のエンコード/デコードを行う Lua コードを生成するブラウザアプリです。BigInt による有理数演算でパッキングを最適化し、限られたビット数やチャンネル数の中でより多くの数値をやり取りしたいビークル開発者向けのツールです。

- BigInt 有理数演算によるパッキング最適化探索
- Vehicle/MC/Lua のセーブツリー管理
- 設定の JSON インポート/エクスポート
- AI アシスタント向けの Markdown 仕様エクスポート
