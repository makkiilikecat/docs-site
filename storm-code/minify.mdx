Storm Code には [StormMin](/tools/stormworks/stormmin/) が組み込まれています。プロジェクト内の複数ファイルを 1 つの Lua スクリプトへリンクし、Stormworks のマイクロコントローラーに貼り付けられる形に圧縮します。

## minify ボタン

エディタ上部の "minify" ボタンを押すと、次の処理が行われます。

1. アクティブなファイルを起点に、`require` されているモジュールをすべてリンクします。
2. 実際に使われている `sim.*` の非公式ライブラリメンバーだけを埋め込みます (tree shaking)。
3. コードを圧縮します。
4. 成功すると、圧縮後のコードが自動的にクリップボードにコピーされ、ボタンに「N字 コピー済み」と表示されます。

ボタンをクリックする前にカーソルを合わせると、直近のコンパイル結果をプレビューできます。プレビューにも「コピー」ボタンがあります。

## エラーになった場合

lint と同じ静的解析 (StormMin の `analyze`) がコンパイル時にも実行されるため、エディタ上で警告が出ていないコードであれば minify も失敗しません。失敗した場合は、エラーパネルに診断内容と「再試行」ボタンが表示されます。エディタ編集中に警告だった項目のうち、次の 2 つは minify 時にはエラーとして扱われます。

- ゲーム内で使えないグローバルの参照
- `onTick` の外での `input`/`output` の呼び出し

これらの diagnostics コードについては [Editor](/storm-code/editor) の lint の項も参照してください。

## 文字数の上限

Stormworks のマイクロコントローラーに貼り付けられるスクリプトには 8192 文字の上限があります。minify 後のコードがこの上限を超えると、コードはクリップボードにコピーされますが、ボタンとエラーパネルの両方に上限超過の警告が表示されます。この場合、ゲーム内に貼り付けられない可能性があります。

<Tip>
コードが上限に収まらない場合は、`sim.*` の非公式ライブラリメンバーの使用を減らす、`require` するモジュールを整理する、コメントを削るなどしてサイズを抑えてください。
</Tip>

## ゲームへの貼り付け

1. minify ボタンでコードをクリップボードにコピーします。
2. Stormworks を起動し、対象のマイクロコントローラーの Lua エディタを開きます。
3. 既存のコードを選択してクリップボードの内容で置き換えます。
