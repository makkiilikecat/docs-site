`F1` (または `Ctrl/Cmd+Shift+P`) を押すと、アプリ内でもこの一覧を確認できます。

## シミュレーション・デバッグ

| キー | 操作 |
|---|---|
| `F5` | 実行 / 再開 |
| `F6` | 一時停止 |
| `F9` | カーソル行のブレークポイントを切り替え |
| `F11` | ステップイン (1 行進める) |

## ファイル・ワークスペース

| キー | 操作 |
|---|---|
| `Ctrl/Cmd+N` | 新規 Lua ファイルを作成 |
| `Ctrl/Cmd+W` | アクティブなタブを閉じる |
| `F2` | Explorer で選択中のノードをインラインリネーム |

<Note>
`Ctrl/Cmd+S` はショートカット一覧上は「ファイル保存 (Save)」と表示されますが、Storm Code に保存操作は無いため実際には何も起こりません。編集内容は常に自動的に保持されます。詳細は [保存・エクスポート・インポート](/storm-code/project-data) を参照してください。
</Note>

## パネル

| キー | 操作 |
|---|---|
| `Ctrl/Cmd+B` | サイドバーの表示/非表示を切り替え |
| `` Ctrl/Cmd+J `` または `` ` `` | 下部パネルの表示/非表示を切り替え |
| `Ctrl/Cmd+Shift+E` | Explorer タブを開く |
| `Ctrl/Cmd+Shift+F` | Search タブを開く |

## エディタ (Monaco 標準)

| キー | 操作 |
|---|---|
| `Ctrl/Cmd+Z` | Undo |
| `Ctrl/Cmd+Y` | Redo |
| `Ctrl/Cmd+X` / `C` / `V` | 切り取り / コピー / 貼り付け |
| `Ctrl/Cmd+F` | 検索 |
| `Ctrl/Cmd+H` | 置換 |
| `Ctrl/Cmd+/` | 行コメントの切り替え |

## ヘルプ

| キー | 操作 |
|---|---|
| `F1` | キーボードショートカット一覧を表示 |
