アプリ内では `F1` (`Help > Keyboard Shortcuts`) からも確認できます。

<Note>
  macOS では `Ctrl` を `Cmd` に読み替えてください。
</Note>

## ファイル

| 操作 | キー |
| --- | --- |
| 新規ファイル | `Ctrl` + `N` |

## 編集

| 操作 | キー |
| --- | --- |
| 元に戻す | `Ctrl` + `Z` |
| やり直す | `Ctrl` + `Y` / `Ctrl` + `Shift` + `Z` |
| 切り取り | `Ctrl` + `X` |
| コピー | `Ctrl` + `C` |
| 貼り付け | `Ctrl` + `V` |
| 検索 | `Ctrl` + `F` |
| 置換 | `Ctrl` + `H` |
| 行コメントの切り替え | `Ctrl` + `/` |

<Note>
  元に戻す / やり直すは**自分が行った変更だけ**が対象です。
  共同編集中に他の参加者の編集が巻き戻ることはありません。
</Note>

## 履歴

| 操作 | キー |
| --- | --- |
| 現在の内容を履歴へ記録する | `Ctrl` + `S` |

<Warning>
  `Ctrl+S` は保存ではありません。本文は常に自動で保存されています。
  これは[履歴に1世代刻む](/storm-code/guides/history)操作です。
</Warning>

## 実行とデバッグ

| 操作 | キー |
| --- | --- |
| 実行 / 再開 | `F5` |
| 一時停止 | `F6` |
| 1ティック進める (停止中はステップイン) | `F11` |
| ブレークポイントの切り替え | `F9` |

## Explorer

Explorer にフォーカスがあるときに効きます。

| 操作 | キー |
| --- | --- |
| 複数選択への追加 / 解除 | `Ctrl` + クリック |
| 範囲選択 | `Shift` + クリック |
| 全選択 | `Ctrl` + `A` |
| 名前を変更 (単一選択のみ) | `F2` |
| 選択を削除 (確認1回でまとめて) | `Delete` |
| 選択をコピー | `Ctrl` + `C` |
| 選択を切り取り | `Ctrl` + `X` |
| フォーカス中のフォルダ (無ければルート) へ貼り付け | `Ctrl` + `V` |
| 開く / フォルダの展開切り替え | `Enter` |
| フォーカス移動 | `↑` `↓` |
| フォルダを展開 / 子へ移動 | `→` |
| フォルダを折りたたみ / 親へ移動 | `←` |

## ワークスペース選択画面

| 操作 | キー |
| --- | --- |
| 一覧を移動 | `↑` `↓` |
| 選択したワークスペースを開く | `Enter` / ダブルクリック |
| パネルを閉じて一覧へ戻る | `Escape` |

## ヘルプ

| 操作 | キー |
| --- | --- |
| ショートカット一覧を開く | `F1` |
