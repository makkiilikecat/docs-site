## 画像

| 項目 | 値 |
| --- | --- |
| 1枚あたり | 1 MB |
| 端末内の合計 | 32 MB |

同じ内容の画像は、何箇所に置いても実体は1つしか保存されません (内容のハッシュで管理されます)。

## 履歴

| 項目 | 値 |
| --- | --- |
| [ファイル履歴](/storm-code/guides/history) — ファイルごとの世代数 | 50 |
| [クラウド世代](/storm-code/guides/history) — 保持する世代数 | 直近50 (区切りの都合で実際は50〜70) |
| クラウド世代 — 最低保証 | **7日以内の世代は何があっても消えません** |

上限を超えたときは、一覧に出ていない世代から優先して消えます。

## クラウドワークスペース

| 項目 | 値 |
| --- | --- |
| 1アカウントが持てる数 | 20 |
| ワークスペース1つあたりの本文サイズ | 8 MB |

画像の上限は本文とは別に判定されます。
本文が上限に達しても、既にあるファイルの編集は続けられます。

## Sim I/O

| 項目 | 値 |
| --- | --- |
| チャンネル番号の範囲 | 1〜32 |

## [Remote MCP](/storm-code/guides/remote-mcp)

| 項目 | 値 |
| --- | --- |
| `exec` の実行時間 | 60秒 |
| 順番待ち | 12秒 (超えると「サーバー過負荷」) |
| `exec_lua` のティック数 | 既定 60 / 最大 216,000 |
| 1プロセスのメモリ | 512 MiB |
| 同時実行数 | 4 |
| `read_file` の切り詰め | 64 KB |
| 実行ログの保持 | ワークスペースごとに直近50件または合計5 MB、TTL 24時間 |
| `grep` の入力 / 出力 / 時間 | 8 MiB / 4 MiB / 1秒 |

## ログ

| 項目 | 値 |
| --- | --- |
| ログパネルの行数 | 5000 行 (超えると「N 行を破棄」が1行出ます) |
| MCP アクティビティの記録件数 | 200 |

## [AI による支援](/storm-code/guides/ai-assist)

| 項目 | 値 |
| --- | --- |
| 応答を待つ時間 | 10秒 |
| エラー解説のキャッシュ | 50件 (そのタブを開いている間) |
| 履歴タイトルの長さ | 30文字以内 |

## その他

| 項目 | 値 |
| --- | --- |
| バックグラウンドで実行を止めるまでの時間 | 30秒 |
| 一時共有でオーナー不在が続いて終了するまで | 60秒 |

<Note>
  クラウド側の上限はサーバーの設定で変わります。
  [ワークスペース選択画面](/storm-code/guides/workspaces)の容量表示は、
  取得できない値を既定値で埋めることはせず、取得できない旨を明記します。
</Note>
