Storm Code で確認できる、主な制限値をまとめています。

## スクリプト・チャンネル

| 項目 | 値 |
|---|---|
| Stormworks に貼り付けられるスクリプトの文字数上限 | 8192 文字 |
| Sim I/O の number/bool 入出力チャンネル数 | 各 1〜32 |

<Note>
デバッグ実行中は、スクリプトが 8192 文字を超えていても実行は止まらず警告のみが表示されます。ただし minify した結果を実際に Stormworks へ貼り付けるには、この上限に収める必要があります。詳細は [Minify とゲームへの貼り付け](/storm-code/minify) を参照してください。
</Note>

## 実行・描画

| 項目 | 値 |
|---|---|
| `onTick` / `onDraw` の既定の実行レート | 60Hz (それぞれ独立に 1〜240Hz へ変更可能) |
| 1 回の `onTick`/`onDraw` あたりの実行時間の上限 | 1000ms (超過するとスクリプトがクラッシュ扱いになります) |
| 1 回の `onDraw` あたりの描画コマンド数の上限 | 65536 個 |
| モニター ID の範囲 | 1〜64 |
| モニター 1 枚の最大サイズ | 768px (32px グリッドで 24 マス) |

## ログ出力

| 項目 | 値 |
|---|---|
| `print` / `debug.log` の 1 行あたりの文字数上限 | 512 文字 |
| 1 回の `onTick`/`onDraw` あたりのログ行数上限 | 32 行 |
| Terminal パネルが保持するログ行数の上限 | 2000 行 (超過分は古いものから破棄されます) |

## 共同編集

| 項目 | 値 |
|---|---|
| プロジェクトサイズの上限 | 8MB (超過するとセッションが自動終了します) |
| ホストが再接続できる猶予時間 | 60 秒 |
| 同期できる画像 1 ファイルのサイズ上限 | 1MB |

詳細は [共同編集](/storm-code/collaboration) を参照してください。
