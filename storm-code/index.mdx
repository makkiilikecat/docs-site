Storm Code は、Stormworks 向けの Lua スクリプトをブラウザ内で書き、
実行・デバッグし、minify してゲームへ貼り付けるまでを1つの環境で行うツールです。
インストールは不要です。

<Warning>
  **旧バージョンにデータがある場合は、アップデート前に旧バージョンの
  `File > Export Zip...` で通常コードを zip へ保存してください。**
  新バージョンは旧バージョンのブラウザ保存データを直接読み替えず、自動移行もしません。
  バックアップ前に旧データを削除したり、全データを初期化したりしないでください。
  すでに新バージョンを開いてしまった場合は[旧バージョンのデータを救出する](/storm-code/guides/legacy-rescue)を参照してください。
</Warning>

## 提供していない機能

- **Storm Code 内の AI Chat / Agent は提供していません。**
  AI が関わるのは[エラー解説と履歴の自動命名](/storm-code/guides/ai-assist)の2つだけです。
  [Remote MCP](/storm-code/guides/remote-mcp) は推論を行わず、利用中の外部エージェントへ
  Storm Code の操作手段を渡す機能です。
- デスクトップアプリはありません。ブラウザのみです。
- オフライン起動には対応していません。

## Beta としての制約

- 保存形式や zip 形式に非互換な変更が入ることがあります。自動 migration は提供しません。
- ローカルワークスペースはブラウザのサイトデータです。ブラウザのデータ削除や端末の故障で失われます。
  [zip を定期的に保存してください](/storm-code/guides/backup)。
- クラウドワークスペースを使う場合も、持ち運べるバックアップが必要なら zip を保存してください。
- 表示言語は日本語のみです。

不具合や説明の不足は、Storm Code の `フィードバック` から報告できます。
