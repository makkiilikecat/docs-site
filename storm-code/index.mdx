Storm Code は、Stormworks 向けの Lua スクリプトをブラウザ内で書き、
実行・デバッグし、minifyしてゲームへ貼り付けるまでを1つの環境で行うツールです。
インストールせずに利用できます。

<Warning>
  **旧バージョンにデータがある場合は、アップデート前に旧バージョンの
  `File > Export Zip...` で通常コードをzipへ保存してください。**
  新バージョンは旧バージョンのブラウザ保存データを直接読み替えず、自動移行もしません。
  バックアップ前に旧データを削除したり、全データを初期化したりしないでください。
</Warning>

<Card title="Storm Code を開く" icon="arrow-up-right-from-square" href="https://www.makkii.jp/tools/stormworks/storm-code/">
  ブラウザで利用します。
</Card>

## 主な機能

- Lua 5.3 WASMによる実行、ブレークポイント、変数・コールスタックの確認
- Stormworksのモニター描画とSim I/Oによる入力・出力の確認
- `require` と `sim.*` ライブラリ、編集中のlint
- StormMinと統合したモジュール結合とminify
- GUIでモニターを組み立てるDesign
- 複数ワークスペース、ファイル履歴、画像、zip export/import
- Googleログインを使うクラウドワークスペース、複数端末同期、クラウド世代と復元
- アカウント不要の一時共有と、メンバーを招待する共同編集
- クラウドワークスペースを外部エージェントから操作するRemote MCP
- Nekoliteを使うエラー解説とファイル履歴名の生成

Storm Code内のAI Chat / Agentは現在提供していません。
Remote MCPは、利用中の外部エージェントへStorm Codeの操作手段を渡す機能です。

## ワークスペースと保存

Storm Codeの編集内容は常にブラウザ内のワークスペースへ反映されます。
「保存」操作はありません。`Ctrl+S` は現在の内容をファイル履歴へ記録する操作です。

| 種類 | 保存先 | 利用できる機能 |
| --- | --- | --- |
| ローカルワークスペース | 利用中のブラウザ | 編集、実行、Design、ファイル履歴、zip、一時共有 |
| クラウドワークスペース | ブラウザとクラウド | 複数端末同期、共同編集、一時共有、画像同期、クラウド世代、Remote MCP |

クラウド機能にはGoogleログインが必要です。
一時共有のゲストはログインせず参加できますが、共有から退出すると端末内の一時データは残りません。

## zipによる移行とバックアップ

ワークスペースの選択画面から、対象ワークスペースのexport、新しいワークスペースの作成、
名前変更、複製、削除、zip importを行えます。
エディタを開いている場合は、`File` メニューから現在のワークスペースをexportできます。

新バージョンのワークスペースzipには、通常ファイル、Design、画像が入ります。
APIキー、Google認証、MCP token、端末のレイアウト、ファイル履歴は含まれません。

### 旧バージョンからの手順

<Steps>
  <Step title="旧バージョンでzipを保存">
    アップデート前に旧バージョンを開き、
    `File > Export Zip...` で通常コードを保存します。
    旧バージョンのexportはDesignやファイル履歴を移行しません。
  </Step>
  <Step title="新バージョンでzipを選択">
    ワークスペース選択画面の「Zipをインポート」を選びます。
    旧バージョンのzipにDesignが入っていても、そのまま渡せます。
    新バージョンで読めないDesignは、その分だけ飛ばして残りを取り込み、
    飛ばした一覧を表示します。zipを開いて作り直す必要はありません。
  </Step>
  <Step title="新しいワークスペースとして確認">
    zipの通常コードが新しいワークスペースへ取り込まれたことを確認します。
    元のワークスペースを上書きしません。
  </Step>
</Steps>

旧バージョンのブラウザDBが残ったまま新バージョンを開くと、
通常起動より先に救出画面を表示します。画面から作る救出バックアップには、
通常コードの `code.zip`、旧DesignのJSON、元DBのrawデータが分かれて入ります。
新バージョンへ通常importできるのは、外側の救出zipを解凍した中の `code.zip` だけです。
旧Designと履歴は自動変換されません。

<Warning>
  救出バックアップの保存を確認するまで、旧データの削除や全データの初期化を行わないでください。
  救出画面の「旧データを削除」は元に戻せません。
</Warning>

## クラウド、共同編集、世代

クラウドワークスペースは、同じGoogleアカウントの別端末から開けます。
オーナーはメンバーを招待でき、申請の承認・reject、kickを管理できます。
メンバーは自分でleaveできます。

一時共有はアカウント不要の短時間の共同作業向けです。
継続的に一覧へ残し、別端末からも開く場合はメンバー共同編集を使います。

クラウド世代はワークスペース全体の復元点です。
ファイル履歴は端末内にあるファイル単位の履歴で、別端末やzipへは移りません。
この2つは保存先と復元範囲が異なります。

## Remote MCP

Remote MCPはクラウドワークスペース専用です。
Googleログイン後に発行したMCP tokenとワークスペースIDを外部クライアントへ設定します。
ブラウザを閉じていても、外部エージェントは許可されたワークスペースのファイル、
診断、Lua実行、Designを操作できます。

MCP tokenは認証情報です。共有せず、zipやソースコードへ入れないでください。
再発行すると以前のtokenは失効します。

## Betaとしての制約

- 保存形式やzip形式に非互換変更が入る場合があります。自動migrationは提供しません。
- ローカルワークスペースはブラウザのサイトデータです。ブラウザのデータ削除や端末故障に備え、zipを定期的に保存してください。
- クラウドワークスペースでも、持ち運べるバックアップが必要な場合はzipを保存してください。
- Nekoliteのエラー解説・履歴名生成では、処理に必要な診断やコードがサービスへ送信されます。秘密情報を含めないでください。
- この2つの送信内容は、既定でAIの学習に使いません。サービス側で学習対象外として固定しており、設定の切り替えには依存しません。
