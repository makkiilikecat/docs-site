Storm Code には粒度の違う2つの履歴があります。**別のものなので、混同しないでください。**

| | ファイル履歴 | クラウド世代 |
| --- | --- | --- |
| 単位 | ファイル1つ | **ワークスペース全体** |
| 中身 | そのファイルの全文 | ツリーを含む全体 |
| **消したファイルを戻せる** | **できない** | **できる** |
| 画像 | 対象外 | 含む |
| 保存先 | この端末の中 | サーバー |
| 使えるワークスペース | すべて | **クラウドワークスペースのみ** |
| 画面 | `履歴` タブ | `クラウド世代` タブ |

ローカルワークスペースが全体の世代を持たないのは、置き場が同じ端末の中にしかなく、
**端末が壊れたら守りたいものと一緒に消えてしまう**ためです。保険になりません。

## 記録される契機

どちらも同じ契機で1世代が刻まれます。

- `Ctrl+S` (明示的な記録)
- 実行
- エクスポート
- 明示的なスナップショット
- Design の自動記録

直前と内容が同じ場合はスキップされます。

<Note>
  **`Ctrl+S` は保存ではありません。** 本文は常に自動で保存されているので、
  保存する操作自体がありません。`Ctrl+S` は「ここを1つの区切りとして残す」ための操作です。
</Note>

## ファイル履歴

`履歴` パネルに世代が並びます。選ぶと差分エディタで現在の内容と比較でき、そこから復元できます。

- **復元する直前に、現在の内容が1世代記録されます。** 巻き戻し自体を巻き戻せます。
- ファイルごとに直近50世代まで残ります。
- 記録は `fileId` に紐づくので、**ファイル名を変えても履歴は繋がります**。
- 画像は対象外です。

### 自動で付く名前

履歴には[自動で日本語のタイトルと説明が付きます](/storm-code/guides/ai-assist)。
同時に「一覧に出すほどの変更か」も判定され、細かすぎる世代は既定で隠れます。

隠れた世代は削除されたわけではありません。
「非表示の履歴を表示」のトグルで全件を確認できます。
上限を超えたときは、隠れている世代から優先して消えます。

`Ctrl+S` で明示的に記録したものは、判定にかかわらず必ず一覧に出ます。

### 端末を越えません

<Warning>
  **ファイル履歴はこの端末の中だけにあります。**
  zip エクスポートにも含まれず、別の端末にも引き継がれません。ワークスペースを複製しても消えます。

  端末を越えて残したい場合はクラウド世代を使ってください。
</Warning>

## クラウド世代

クラウドワークスペースだけが持つ、ワークスペース全体の復元点です。
`クラウド世代` タブから確認します。

### 2種類の復元

| 操作 | 影響範囲 | 権限 |
| --- | --- | --- |
| ワークスペース全体をその世代へ戻す | 全体を置き換え、参加者全員が読み直す | オーナーのみ |
| いま存在するファイルを、その世代の内容へ戻す | そのファイルの本文だけ | オーナー |
| 削除済みのファイルを、その世代から復元する | ファイルが1つ増える | オーナー |

<Warning>
  **削除済みのファイルを復元すると、それは新しいファイルとして作られます。**
  削除前のファイル履歴は引き継がれません。復元時にその旨が表示されます。
</Warning>

### 保持

| 項目 | 値 |
| --- | --- |
| 保持する世代 | 直近50世代 (区切りの都合で実際は50〜70) |
| 最低保証 | **7日以内の世代は何があっても消えません** |

画像は内容のハッシュで1部だけ保存され、各世代はそれを参照するだけです。
10世代あっても画像は1部しか持ちません。

### 全体復元をすると他の端末が読み直します

ワークスペース全体を戻すと、他の端末で開いているものは自動で読み直されます。

これは操作感のためではなく、**正しさのために必要**です。
巻き戻す前の状態を持った端末が1台でも再接続すると、
巻き戻したはずの内容が同期で復活してしまいます。
そのため、古い状態を持った接続は同期せずに破棄し、新しい状態を取り直します。
