**zip はワークスペースの唯一の完全な可搬形式です。**
別のブラウザへ移す、他の人に渡す、手元の VS Code で開く、といった用途に使えます。

<Warning>
  ローカルワークスペースはブラウザのサイトデータです。
  ブラウザのデータ削除、プライベートウィンドウの終了、端末の故障で失われます。
  **定期的に zip を保存してください。**
</Warning>

## エクスポート

| 場所 | 対象 |
| --- | --- |
| `File > Export Zip...` | いま開いているワークスペース |
| [ワークスペース選択画面](/storm-code/guides/workspaces) | 一覧から選んだワークスペース |

## zip に入るもの・入らないもの

| 対象 | zip |
| --- | --- |
| ファイルとフォルダ | 入る |
| Design | 入る |
| 画像 | 入る |
| スニペット (`.scode/snippets.json`) | 入る |
| [ファイル履歴](/storm-code/guides/history) | **入らない** |
| パネル幅・開いていたタブ・カーソル位置 | **入らない** |
| Google ログイン情報・[MCP トークン](/storm-code/guides/remote-mcp)・API キー | **入らない** |

履歴やレイアウトが入らないのは、**zip が「プロジェクトの可搬形式」であって
「その端末のアプリ全体のスナップショット」ではない**ためです。
パネルの幅を他人に渡しても意味がありませんし、認証情報は他人に渡ってはいけません。

zip は平文で、フォルダ構造もそのままです。展開すれば普通のエディタで開けます。

zip の内部構造は [zip の形式](/storm-code/reference/zip-format)を参照してください。

## インポート

| 場所 | 結果 |
| --- | --- |
| ワークスペース選択画面の「Zip をインポート」 | 新しいワークスペースとして開く |
| `File > Import Zip...` | 新しいワークスペースを作ってそこへ移動する |

**どちらから実行しても、いま開いているワークスペースは一切変更されません。**
そのため確認ダイアログもありません。

### 取り込めないものがあった場合

| 内容 | 挙動 |
| --- | --- |
| パスの文法違反・重複 | **診断として一覧表示し、1件でもあれば取り込みを中断する** |
| 許可していない拡張子 | 無視し、スキップした一覧を表示する |
| 読めない Design | **その `.design` だけを飛ばし、飛ばしたものを表示する** |

Design だけ扱いが違うのは、Design 1件のために zip 全体を拒否すると、
**同じ zip に入っている通常のコードまで取り込めなくなる**ためです。
それ以外のものを黙って減らすことはしません。

### 形式のバージョン

zip には `.scode/workspace.json` として形式の種類とバージョンが入ります。
名乗ったバージョンに対応していなければ、明示的に拒否します。
中途半端に読み込んでデータを壊すことはしません。

マニフェストが入っていない普通の zip は、パスと拡張子の検証だけを通して受け入れます。

## フォルダやファイルを直接取り込む

`File > Open Folder...` / `Open File...` でも取り込めます。
zip インポートと同じ検証を通ります。

<Warning>
  `Open Folder...` は**いま開いているワークスペースの中身を置き換えます**。
  実行前に確認ダイアログが出ます。
</Warning>

## 別のブラウザへ移す

<Steps>
  <Step title="元のブラウザでエクスポート">
    `File > Export Zip...` で zip を保存します。
  </Step>
  <Step title="新しいブラウザでインポート">
    Storm Code を開き、ワークスペース選択画面の「Zip をインポート」から取り込みます。
  </Step>
  <Step title="確認する">
    ファイル、Design、画像が揃っていることを確認します。
    **ファイル履歴は移りません。** これは仕様です。
  </Step>
</Steps>

端末を越えて履歴まで残したい場合は、zip ではなく
[クラウドワークスペース](/storm-code/guides/cloud)を使ってください。
