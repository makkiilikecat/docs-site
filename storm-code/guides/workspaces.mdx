ワークスペースは、Storm Code が扱う作業単位です。
1つのワークスペースが、ファイルツリー・本文・Design・画像・スニペットを1組持ちます。

## 選択画面

ワークスペースを開いていない状態で表示されるのが選択画面です。
**ワークスペースが1つも開けない状態でも動く唯一の画面**なので、復旧に必要な操作はすべてここにあります。

| 欄 | 内容 |
| --- | --- |
| 左 | ログイン、新規作成、zip インポート、フィルター |
| 中央 | 検索できる一覧 |
| 右 | 選択したワークスペースの詳細 |

一覧では名前で検索でき、「すべて / ピン留め / クラウド / この端末のみ / 参加中」で絞り込めます。
最終アクセス順・名前順のどちらでもピン留めしたものが先に来ます。

- PC ではクリックで詳細を表示、ダブルクリックまたは `Enter` で開きます。
- `↑` `↓` で一覧を移動します。
- タッチ操作では選択すると詳細が出て、「ワークスペースを開く」で移動します。

詳細欄には、ルートの `README.md` の内容、端末内の直近のファイル履歴5件、容量の概算が出ます。
`README.md` は読み取り専用で表示され、外部画像の自動取得や相対リンクでの遷移は行いません。

<Note>
  持ち物が1つも無いときは選択画面を見せず、`My Project` を作ってそのまま開きます。
  ただし**ログイン中にサーバーの一覧取得に失敗した場合は作りません** —
  「本当に0件」なのか「見えていないだけ」なのか区別できないためです。
  この場合は警告付きの空の状態で止まります。
</Note>

## 開いているワークスペースは URL が持つ

アドレスの `#w=<workspaceId>` が、いま開いているワークスペースの正本です。
ハッシュが無ければ選択画面になります。

リロードで元のワークスペースに戻るのは URL に載っているからです。
「最後に開いたもの」を別に記憶してはいません。URL をブックマークすれば、そのワークスペースを直接開けます。

## ローカルとクラウド

| | ローカルワークスペース | クラウドワークスペース |
| --- | --- | --- |
| 保存先 | 使っているブラウザだけ | ブラウザとサーバーの両方 |
| Google ログイン | 不要 | 必須 |
| 複数端末から開く | できない | できる |
| [共同編集](/storm-code/guides/sharing) | できない | できる |
| [一時共有](/storm-code/guides/sharing) | できる | できる |
| [クラウド世代](/storm-code/guides/history) | 無い | ある |
| [Remote MCP](/storm-code/guides/remote-mcp) | 使えない | 使える |

ローカルからクラウドへの切り替え (クラウド化) と、その逆は `ワークスペース` メニューから行います。
手順は[クラウドワークスペース](/storm-code/guides/cloud)を参照してください。

## 操作

作成・複製・名前変更・削除・エクスポート・zip インポート・全データの初期化は選択画面から行います。

<AccordionGroup>
  <Accordion title="新規作成">
    空のワークスペースを作ります。名前は後から変更できます。
  </Accordion>
  <Accordion title="複製">
    「エクスポートして、そのまま新しいワークスペースとしてインポートする」のと同じ範囲をコピーします。

    したがって**ファイル履歴は複製されません**。zip インポートで履歴が入らないのと同じ挙動です。
  </Accordion>
  <Accordion title="名前を変更">
    クラウドワークスペースの名前変更はオーナーのみです。
    メンバーには読み取り専用の名前欄と、離脱の操作が出ます。
  </Accordion>
  <Accordion title="エクスポート / zip インポート">
    選択画面のエクスポートは**一覧から選んだワークスペース**が対象です。
    `File` メニューのエクスポートは**いま開いているワークスペース**が対象です。

    zip インポートはどちらから実行しても、**新しいワークスペースとして開きます**。
    現在のワークスペースは一切変更されないので、確認ダイアログもありません。

    詳細は [zip でバックアップ・移行する](/storm-code/guides/backup)を参照してください。
  </Accordion>
  <Accordion title="削除">
    そのワークスペースに属するデータを消します。
    クラウドワークスペースの削除はオーナーのみです。
  </Accordion>
  <Accordion title="全データを初期化">
    この端末の Storm Code のデータをすべて消します。起動に失敗したときの最後の手段です。

    <Warning>
      元に戻せません。実行する前に必要なワークスペースを zip でエクスポートしてください。
    </Warning>
  </Accordion>
</AccordionGroup>

## 同じワークスペースを2つのタブで開いたとき

**後から開いたタブが読み取り専用になります。** 読み取り専用バナーが表示されます。

同じ保存先を2つのタブが同時に書くと壊れるためで、**違うワークスペースを2つのタブで開く分には両方とも編集できます**。
読み取り専用のタブからは一時共有を開始できません。

## 容量の表示

選択画面の容量欄は、ブラウザが返す**サイト全体**の使用量と割当量の概算です。
ワークスペースごとの割当ではありません。

画像については、端末内の使用量と上限を表示します
(合計 32 MB、1枚あたり 1 MB)。
クラウドワークスペースの本文使用量はサーバーの一覧から取得します。

<Note>
  本文の上限はサーバーの設定次第で変わるため、現在の API では取得できません。
  画面には「取得できない」と明記しています。既定値を実際の上限として表示することはしません。
</Note>
