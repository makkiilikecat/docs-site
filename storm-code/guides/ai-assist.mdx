Storm Code が AI を使うのは**2つの機能だけ**です。

| 機能 | 起きるとき |
| --- | --- |
| エラーの解説 | 自分でボタンを押したとき |
| ファイル履歴の自動命名 | 履歴が記録されるたび、自動で |

推論は [Nekolite](https://www.makkii.jp/terms.html) という AI サービスが行います。

<Note>
  **Storm Code 内の AI Chat / Agent は提供していません。**
  [Remote MCP](/storm-code/guides/remote-mcp) は推論を行わず、
  利用中の外部エージェントへ操作手段を渡す機能です。

  AI の設定項目もありません。使うモデルやプロンプトはすべてサーバー側にあります。
</Note>

## エラーの解説

診断の内容が分からないときに、説明を求められます。

| 場所 | 操作 |
| --- | --- |
| `Problems` パネル | 各エラー行の右端の「AI に聞く」ボタン |
| エディタ | 波線にカーソルを合わせるか電球アイコンから「AI にエラーの解説を聞く」 |

ポップアップに3つのテキストが出ます。

1. **エラーの解説** — その診断が何を言っているか
2. **発生理由** — なぜ起きたか
3. **具体的な直し方** — どう直すか (クリップボードへのコピーボタン付き)

<Note>
  **提案が自動で適用されることはありません。** ポップアップ内で直接コードを編集することもできません。
  読んで、自分で直してください。
</Note>

同じ内容の質問は、そのタブを開いている間キャッシュされます (最大50件)。

## ファイル履歴の自動命名

[履歴](/storm-code/guides/history)が記録されるたびに、裏で自動的に実行されます。

- 変更内容を表す**30文字以内の日本語のタイトル**と、説明文が付きます。
- 同時に「一覧に出すほどの変更か」も判定され、細かすぎる世代は既定で隠れます。

`Ctrl+S` で明示的に記録したものは、判定にかかわらず必ず一覧に出ます。

隠れた世代は削除されたわけではありません。
「非表示の履歴を表示」のトグルで全件を確認できます。

### 送信される内容

- 変更前と変更後のファイルの内容
- 近くにある `.lua` ファイルの相対パス一覧
- 直近の履歴タイトル一覧
- `Ctrl+S` だったかどうか、前回からの経過時間、編集した文字数

## 送信されるものと、その扱い

<Warning>
  **処理には、書いたコードそのものが必要です。**
  要配慮個人情報、他の人の個人情報、API キーやパスワードなどの認証情報、
  秘密にすべき情報は入力しないでください。
</Warning>

- **この2つの機能が送るものは、既定で AI の学習に使いません。**
  サーバー側で学習の対象外として固定されており、設定の切り替えに依存しません。
- ただし、**学習に使わないことと、記録が残らないことは別です。**
  送信内容は、障害の調査・不正利用への対処・品質改善のための記録として保持されます。
  日常的に閲覧することはなく、参照するのは個別の障害対応など必要が生じたときだけです。

詳しくは [プライバシーポリシー](https://www.makkii.jp/privacy.html) と
[利用規約](https://www.makkii.jp/terms.html) を参照してください。

## 失敗したとき

応答が得られない場合は、その旨が画面に表示されます。
**黙って空の結果を返すことはありません。**

サーバー側が混み合っている場合や、応答に時間がかかりすぎる場合 (10秒) はエラーになります。
少し待ってから試してください。

### AI が使えなくても Storm Code は動きます

エラーの解説は押さなければ発生せず、履歴の自動命名が失敗しても履歴自体は記録されます。
AI が止まっている間も、編集・実行・minify・同期はすべて通常どおり使えます。

## 直接アクセスしないでください

<Warning>
  Storm Code のクライアントを経由せずに Nekolite の API へ直接アクセスすることは、
  [利用規約](https://www.makkii.jp/terms.html) で禁止されています。
  検知された場合、アクセスが制限されることがあります。
</Warning>
