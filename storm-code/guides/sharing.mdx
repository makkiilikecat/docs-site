共有には**2つのモード**があります。目的が違うので、使い分けてください。

| | 一時共有 | 共同編集 |
| --- | --- | --- |
| 参加する人 | ゲスト (匿名) | メンバー (アカウント) |
| Google ログイン | 不要 | **必須** |
| 対象 | ローカル / クラウドどちらでも | **クラウドのみ** |
| 参加方法 | リンクを開く | 招待 → 申請 → オーナーの承認 |
| 自分の一覧に載るか | 載らない | **載る** |
| オーナーがいなくなったら | 編集が止まり、60秒で終了 | **そのまま続けられる** |
| 終わり方 | セッション終了 / 本人が離脱 | キック / 本人が離脱 / ワークスペース削除 |
| zip の取得 | できない | 在籍中はできる |

どちらも `共有` ウィンドウから操作します。同時に両方を有効にもできます。

## 一時共有

短時間、誰かに手伝ってもらうためのものです。相手にアカウントは要りません。

<Steps>
  <Step title="開始する">
    `共有` ウィンドウの「一時共有」から開始し、出てきたリンクを相手に渡します。
  </Step>
  <Step title="相手が参加する">
    相手はリンクを開くだけで参加できます。自分のワークスペースを開く必要はありません。
  </Step>
  <Step title="終了する">
    明示的に停止するか、オーナーが離れて60秒経つと終了します。
  </Step>
</Steps>

<Warning>
  **リンクを知っている人は誰でも編集できます。** 配る範囲は自分で管理してください。
</Warning>

### ゲスト側で起きること

- ワークスペースはブラウザに保存されません。
- 終了すると、内容・タブ・実行状態・受け取った画像がすべて破棄されます。
- **終了後に内容を取り出す手段はありません。** 退出した理由が表示され、自分の画面へ戻ります。
- オーナーの接続がすべて途切れている間は書き込めません。60秒以内にオーナーが戻れば再開します。

### 画像

ローカルワークスペースの一時共有では、オーナーが手動で画像をゲストへ送ります。
クラウドワークスペースの自動同期とは別の経路です。

## 共同編集 (メンバー)

継続的に一緒に作業する相手向けです。クラウドワークスペースでのみ使えます。

<Steps>
  <Step title="招待リンクを渡す">
    `共有` ウィンドウの「メンバー」から招待リンクを発行します。リンクは繰り返し使えます。
  </Step>
  <Step title="相手が申請する">
    リンクを開くと申請画面が出ます。相手は Google ログインをして、
    表示名を入力したうえで明示的に申請を送ります。

    <Note>
      **リンクを開いただけでは何も見えません。** 閲覧も編集もできません。
      権限が渡るのはオーナーが承認したあとです。
    </Note>
  </Step>
  <Step title="オーナーが承認する">
    申請が一覧に並ぶので、承認するか却下します。
  </Step>
</Steps>

承認されたワークスペースは、メンバー自身の選択画面の一覧にも並びます。

<Note>
  表示名は自己申告です。本人確認ではありません。
  Google のメールアドレスなどが参加者に表示されることはありません。
</Note>

### できること

| 操作 | オーナー | メンバー |
| --- | --- | --- |
| 本文・Design・ファイル・画像の編集 | できる | できる |
| ワークスペースの名前変更・削除 | できる | できない |
| 招待・承認・却下・キック | できる | できない |
| [クラウド世代](/storm-code/guides/history)の一覧・全体復元 | できる | できない |
| 一時共有の発行・停止 | できる | できない |
| 自分が離脱する | — | できる |

### 参加が終わるとき

離脱、キック、ワークスペースの削除のいずれでも参加は終わります。
その人が接続している**すべてのタブ・すべての端末**が切断されます。

手元にあった対象ワークスペースのデータは破棄されます。
接続していなかった端末には、次に接続したときに反映されます。

<Note>
  破棄はクライアント側の動作の取り決めです。
  既に手元へコピーされたデータを回収することや、
  切断されている端末から即座に消すことは保証できません。
</Note>

## 同期されるもの・されないもの

| | 同期 |
| --- | --- |
| ファイルの本文・ツリー・Design・スニペット・設定 | される |
| 画像 | される (ハッシュを見て必要なものだけ転送) |
| タブの配置・開いているタブ・カーソル位置 | されない |
| 検索・ブレークポイント・Watch 式 | されない |
| 実行状態 | されない |
| 個人の設定 | されない |

同期されないものは「その端末の作業の状態」であって、ワークスペースの内容ではないためです。

接続中の参加者の表示名・色・選択位置は互いに見えます。
ゲストとメンバーは区別して表示されます。

## 権限はサーバーが確認します

参加の可否は毎回サーバーで検証されます。画面上の表示だけを信用することはありません。
キックや期限切れは、既に繋がっている接続にも即座に反映されます。
