Storm Code を開くと、1 つのブラウザにつき 1 つのワークスペースが自動的に用意されます。アカウント登録は不要で、ファイルの作成からすぐに始められます。

## ワークスペースの構成

Storm Code のワークスペースは、複数のプロジェクトを切り替える仕組みではなく、ブラウザごとに 1 つだけ存在します。ワークスペース全体を作り直したい場合は `File > Reset All (Factory Reset)...` でリセットするか、`File > Open Folder...` / `File > Import Zip...` で内容を丸ごと置き換えます (詳細は [プロジェクトの保存・エクスポート・インポート](/storm-code/project-data) を参照してください)。

ワークスペースの中身はファイルとフォルダのツリーです。ノードの種類は次の3つです。

- **ファイル** — Lua スクリプト (`.lua`) のほか、`.md` / `.txt` / `.json` / `.jsonl` を作成できます。
- **フォルダ** — ファイルをまとめるディレクトリです。
- **Design** — GUI 描画エディタで作成する画面レイアウトです。詳細は [Design](/storm-code/design) を参照してください。

新規ワークスペースには、`require` を使った複数ファイル構成の例として、3D 描画のサンプルプロジェクト (`main.lua` から `lib/math3d.lua` などを `require` する構成) が自動的に作成されます。

## Explorer

左サイドバーの Explorer で、ファイル・フォルダ・Design を管理します。

- 背景を右クリックすると `New File` / `New Folder` / `New Design` のメニューが表示されます。
- ファイル・フォルダ・Design はそれぞれの項目を右クリックして `Rename` / `Delete` できます。削除には確認ダイアログが表示されます。
- ノードを選択して `F2` を押すと、その場でリネームできます (VSCode と同様のインライン編集)。
- ノードをドラッグ&ドロップすると、別のフォルダへ移動したり、ツリーのルートへ戻したりできます。

新規ファイルの既定名は `script.lua`、新規フォルダは `New Folder`、新規 Design は `design.design` (以降 `design1.design` のように連番) です。拡張子を付けずにファイル名を入力すると、自動的に `.lua` が補われます。

<Note>
共同編集にゲストとして参加している間も Explorer の操作はできますが、ファイル・フォルダの作成/リネーム/削除/移動はホストへ転送されて処理されます。ホストが切断している間は読み取り専用になります。詳細は [共同編集](/storm-code/collaboration) を参照してください。
</Note>

## ファイル・フォルダの命名ルール

- フォルダ名と `.lua` ファイルのベース名 (拡張子を除いた部分) は、Lua の識別子として有効な文字列 (`[A-Za-z_][A-Za-z0-9_]*`) である必要があります。これは、ファイルパスと `require` のモジュール名を相互に変換できるようにするための制約です (詳細は [require とライブラリ](/storm-code/require-and-libraries) を参照してください)。
- `.lua` 以外の拡張子 (`.md` / `.txt` / `.json` / `.jsonl`) のファイル名は、`/` や制御文字を含まず、`.` や `..` そのものでなければ使えます。
- 同名の衝突は許可されません。自動的に連番が付くことはなく、作成・リネームはエラーになります。
- フォルダ名に `sim` は使えません (`sim` は組み込みライブラリの名前空間として予約されています)。一方、`sim.lua` という名前のファイルは任意の階層に作成できますが、この名前は `require` のモジュール解決の対象から除外される特別なファイルです。
- ルート直下の `.scode` フォルダは IDE 内部の設定領域 (AI 設定など) として予約されています。

## 保存について

Storm Code に明示的な「保存」操作はありません。Monaco エディタでの編集はブラウザの IndexedDB に自動的に反映され続けます (`Ctrl+S` を押しても何も起こりません)。

同じワークスペースを複数のタブで同時に開くことはできません。既に開いているタブがある状態で別のタブを開くと、そちらは読み取り専用モードになります。
