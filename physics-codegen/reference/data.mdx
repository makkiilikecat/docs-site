## 編集中の設定の自動保存

編集中のオフセット構成と Basic Settings は、変更のたびにブラウザの localStorage へ自動保存されます。ページを再読み込みしても失われません。別のブラウザ・別の端末とは共有されません。

## セーブ管理（Vehicle ❯ MC ❯ Lua）

右パネルの「セーブ管理」では、編集中の設定とは別に、複数の構成を「ビークル ❯ MC（マイクロコントローラー）❯ Lua スロット」の階層で保存できます。ビークルごとに複数の MC、MC ごとに複数の Lua スロットを持てます。これも localStorage に保存され、編集中の設定とは独立したデータです。

<Steps>
  <Step title="ビークルを作成する">
    「＋ ビークル」で新しいビークル（親フォルダ）を作成します。作成すると、既定で `Main_MC` という MC と、その中に現在編集中の設定を保存した Lua スロットが1つ作られます。
  </Step>
  <Step title="MC・Lua スロットを追加する">
    ビークル行の＋ボタンで MC を追加できます。MC 行の＋ボタンで、現在編集中の設定を新しい Lua スロットとして保存できます。
  </Step>
  <Step title="スロットをロード・上書き保存する">
    Lua スロットをクリックするとエディタにその設定がロードされ、現在編集中の設定が置き換わります。スロット行の保存アイコンで、現在編集中の設定をそのスロットへ上書き保存できます。ヘッダー右上の保存アイコン（クイックセーブ）は、現在選択中のスロットへ上書き保存するショートカットです。選択中のスロットがない場合は通知が表示されます。
  </Step>
  <Step title="削除する">
    ビークル・MC・Lua スロットはそれぞれ削除できます。削除前に確認ダイアログが表示されます。ビークルや MC を削除すると、その配下のデータもまとめて削除されます。
  </Step>
</Steps>

ヘッダー下のバナーには、現在ロード中のスロットのパス（`ビークル名 / MC名 / Luaファイル名`）と最終更新日時が表示されます。新規未保存の状態では「未選択 (新規・未保存)」と表示されます。

## JSON インポート/エクスポート

ヘッダーの「エクスポート」で、現在編集中の設定（Basic Settings とすべてのオフセット構成）を `physics-codegen-config.json` としてダウンロードできます。「インポート」で、そのようなJSONファイルを読み込み、現在編集中の設定を置き換えられます。

<Warning>
  インポートは Vehicle/MC/Lua のセーブツリーではなく、現在編集中の設定だけを置き換えます。セーブツリー自体の入出力機能はありません。
</Warning>

インポートするファイルは `settings` オブジェクトと `frames` 配列を持つ必要があります。どちらかが欠けている、または JSON として解析できないファイルを選ぶと、インポートは行われず「設定ファイルの解析に失敗しました」という通知が表示されます。フィールドの一部が欠けている場合は、既定値で補完されます。同じ形式の JSON を [HTTP API](/physics-codegen/reference/api) の `POST /api/generate` にもそのまま渡せます。

## すべて初期化

ヘッダーの「全て初期化」は、確認ダイアログの後、編集中の設定とセーブ管理のツリーの両方を初期状態（サンプルのオフセット構成が入った状態）に戻します。この操作は取り消せません。

## AI プロンプトエクスポート

ヘッダーの「AIプロンプト」ボタンから、ChatGPT や Claude などの AI アシスタントに Physics Frame Codegen の仕様を説明するための Markdown を表示できます。「現在編集中の設定データ (JSON) を末尾に含める」にチェックが入っている場合、現在の設定 JSON もあわせて出力されます。「コピー」でクリップボードにコピー、「.md保存」でファイルとしてダウンロードできます。この Markdown には Composite Input チャンネルの割り当てや JSON スキーマ、[HTTP API](/physics-codegen/reference/api) の説明が含まれており、AI アシスタントに構成の生成やコードのゴルフ（圧縮）を依頼する際の文脈として使えます。
